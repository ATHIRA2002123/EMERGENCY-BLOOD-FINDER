# 🩸 Emergency Blood Finder

**Find Blood. Save Lives. Connecting people with nearby blood banks during emergencies.**

A Flask web application that helps people quickly find blood banks and available blood groups in an emergency. Search by blood group and location, view blood bank details, and get the information you need when every minute counts.

---

## 📌 Overview

In emergencies, finding the right blood group at a nearby blood bank can be slow and stressful. **Emergency Blood Finder** brings blood bank information into one simple, searchable interface so users can locate the blood they need without making multiple calls or searches.

## ✨ Features

- 🔍 Search blood banks by blood group and location
- 🏥 View blood bank details such as name, address and contact information
- 🩸 Check availability of different blood groups
- 🗄️ Lightweight data storage using SQLite
- 💻 Simple, responsive web interface built with HTML, CSS and JavaScript

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Backend | Python, Flask |
| Database | SQLite |
| Frontend | HTML, CSS, JavaScript |

## 💡 Usage

1. Open the home page.
2. Select the required blood group and enter your location.
3. Browse the list of matching blood banks.
4. Contact the blood bank using the details shown.
